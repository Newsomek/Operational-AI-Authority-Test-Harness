# V1.0.3 - Independent Review Remediation

V1.0.3 is a focused remediation release following independent adversarial review of V1.0.2.

The published V1.0.2 tag and release remain unchanged. This release preserves that reviewed baseline and publishes the corrective work as a new immutable version.

## What changed

- Corrected authority-boundary handling identified through independent review.
- Enforced strict NARROW semantics so narrowing cannot broaden another authority dimension.
- Made CONDITION operationally causal through a typed supervisor-confirmation predicate.
- Corrected separated-architecture decision-actor propagation.
- Prevented NARROW-specific assertions from leaking into unrelated dispositions.
- Synchronized technical-validity status and explanatory evidence.
- Improved simultaneous boundary-violation evidence.
- Strengthened single-run authority-history and event-log evidence.
- Updated regression tests and governance/decision documentation.

## Validation

Before publication, the remediation passed:

- the internal browser/CDP gate: 16/16 authoritative tests, 0 failed rendered test rows, and 0 ordinary-application smoke failures;
- the corrected external unattended matrix: 336 cases, 224 material-governed PASS cases, 112 expected non-material rejections, and 0 failures;
- 0 prediction-caused execution divergences;
- 0 architecture-caused execution divergences;
- 8/8 CONDITION causal YES/NO pairs with 0 failures;
- repository postcondition verification with the validated thirteen-file remediation unchanged by the external matrix.

## Interpretation

This harness does not prove that a governance architecture is universally correct. It tests a narrower operational claim: governance becomes operational when an authority decision changes the enforceable boundary that downstream execution consumes.

V1.0.3 incorporates the findings of the first independent adversarial review while retaining the original V1.0.2 publication as the historical review baseline.
